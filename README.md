# Medical Cost Prediction with Regression

This project is part of the FreeCodeCamp Machine Learning with Python certification.

## Project Overview

The goal of this project is to predict individual medical insurance costs using a machine learning regression model built with TensorFlow and Keras.

The dataset contains information such as:

- Age
- Sex
- BMI
- Number of Children
- Smoking Status
- Region
- Insurance Charges

## Technologies Used

- Python
- Pandas
- NumPy
- TensorFlow
- Keras
- Matplotlib

## Dataset

The dataset used in this project is:

insurance.csv

Source:
https://cdn.freecodecamp.org/project-data/health-costs/insurance.csv
